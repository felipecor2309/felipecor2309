## Proyectos

### 🛒 [Análisis de Ventas — SuperStore](https://github.com/felipecor2309/Analisis-de-Ventas---SuperStore)
> SQL · Excel · Power BI

Análisis de 9.994 órdenes de una tienda retail (2014–2017) para identificar rentabilidad por categoría, región y producto.

**Hallazgo clave:** La región West genera $715M en ventas y los 3 productos con mayores pérdidas apuntan a problemas de política de precios.

---

### 🎵 [Spotify — Tendencias y Popularidad Musical](https://github.com/felipecor2309/Spotify-Tendencias-y-Popularidad-Musical)
> Python · SQL · Power BI

Análisis exploratorio de +114.000 canciones para identificar artistas, géneros y patrones en características musicales como energía y bailabilidad.

**Hallazgo clave:** The Beatles lidera popularidad acumulada y Pop-film supera al pop mainstream en popularidad promedio.

---

### 👥 [Rotación de Empleados — Análisis HR](https://github.com/felipecor2309/Rotacion-de-Empleados---Analisis-HR)
> Python · SQL · Power BI

Exploración de 1.470 registros de empleados para identificar factores de rotación y construir el perfil del empleado con mayor riesgo de renuncia.

**Hallazgo clave:** Los empleados con horas extra rotan casi 3 veces más (30.5%) que los que no las hacen (10.4%).
