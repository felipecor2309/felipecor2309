## Proyectos
# 🛒 Análisis de Ventas — SuperStore
SQL · Excel · Power BI

Análisis de 9.994 órdenes de una tienda retail (2014–2017) para identificar rentabilidad por categoría, región y producto.
Hallazgo clave: La región West genera $715M en ventas y los 3 productos con mayores pérdidas apuntan a problemas de política de precios.
